# 🎙️ Jahongir Otajonov - Music Platform

CustomTkinter, Pygame va yt-dlp asosida yaratilgan zamonaviy musiqa pleyeri. YouTube orqali Jahongir Otajonovning eng sara qo'shiqlarini onlayn qidirib, ijro etadi.

## 🌟 Imkoniyatlar
- 🎨 **Samsung Music Style Dark UI**: Zamonaviy Dark Glassmorphism dizayn
- 🌐 **Online Streaming**: YouTube orqali qo'shiqlarni avtomatik qidirish va yuklash
- ⏱️ **Seekbar & Dynamic Timer**: Qo'shiqning joriy vaqti va umumiy davomiyligini ko'rsatish
- 🔊 **Ovoz boshqaruvi**: Volume slayderi
- ⏭️ **Avtomatik o'tish**: Tarona tugagach keyingisiga avtomatik o'tish
- 📂 **Kesh tizimi**: Bir nechta qo'shiq almashtirilganda fayllar bloklanishining oldini olish

## 🛠️ O'rnatish

1. Kerakli Python kutubxonalarini o'rnating:
```bash
pip install -r requirements.txt
```

2. Tizimda **FFmpeg** mavjudligiga ishonch hosil qiling (Windows):
```powershell
winget install Gyan.FFmpeg
```

## ▶️ Ishga tushirish

```bash
python main.py
```
